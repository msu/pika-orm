## Query stuff

| name                                                      | description                                                  | example                                                |
| :-------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------- |
| **[on](https://hyperscript.org/features/on)**             | Creates an event listener                                    | `on click log "clicked!"`                              |
| **[def](https://hyperscript.org/features/def)**           | Defines a function                                           | [see details...](https://hyperscript.org/features/def) |
| **[init](https://hyperscript.org/features/init)**         | Initialization logic to be run when the code is first loaded |                                                        |
| **[set](https://hyperscript.org/features/set)**           | Defines a new [element-scoped](https://hyperscript.org/docs#names_and_scoping) variable |                                                        |
| **[behavior](https://hyperscript.org/features/behavior)** | Define cross-cutting behaviors that are applied to many HTML elements |                                                        |
| **[install](https://hyperscript.org/features/behavior)**  | Install a behavior onto the current element                  | `install Draggable`                                    |
| **[js](https://hyperscript.org/features/js)**             | Embed JavaScript code at the top level                       | [see details...](https://hyperscript.org/features/js)  |
| **[live](https://hyperscript.org/features/live)**         | Declare reactive commands that re-run when dependencies change | `live set $total to ($price * $qty)`                   |
| **[when](https://hyperscript.org/features/when)**         | React to value changes with side effects, async, or events   | `when $x changes ...`                                  |
| **[bind](https://hyperscript.org/features/bind)**         | Two-way sync between any two values                          | `bind .dark and #toggle's checked`                     |
