★ Anatomy

The whole API,
on one button.

fixi turns plain HTML elements into hypermedia controls. Add a few attributes, get an AJAX request and a swap.

The HTML

<!-- click → GET /content → swap into #out -->
<button
  fx-action="/content"
  fx-method="get"
  fx-trigger="click"
  fx-target="#out"
  fx-swap="innerHTML">
  Get content
</button>

<output id="out"></output>

The Result

click the button — content will appear here.
★ Attributes

Six attributes.
That's the whole thing.

fx-actionURL to issue the request to
fx-methodHTTP method (get, post, put, delete...)
fx-triggerEvent that triggers the request
fx-targetElement to swap response into
fx-swapHow to swap (innerHTML, outerHTML, beforeend, ...)
fx-confirmConfirmation prompt before request
★ The Fence

What fixi is,
and what it isn't.

fixi is

  • HTML attributes that fire HTTP requests
  • Six attributes you can hold in your head
  • One script tag, no build, no config
  • A foundation moxi/paxi/ssexi/rexi extend

fixi isn't

  • A virtual DOM, a renderer, a compiler
  • A state manager or a router
  • Hyperscript, alpine, htmx feature-for-feature
  • Trying to be everything to everyone
Like a fixed-gear bike, fixi has very few moving parts.
